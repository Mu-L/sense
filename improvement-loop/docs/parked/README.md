# parked/

Loop one-pagers that are **not live**. They are here because they describe work the program
has not reached, and because a page nobody runs sitting next to pages that are run is how a
session ends up hand-walking a loop that does not exist.

Nothing in this folder is authority. When one of these becomes live it is rewritten as a plan
in `../../plans/`, and writing that plan IS the review - a 120-line one-pager cannot be
reviewed any other way.

|---|---|---|
| `04-matrix-fill.md` | not live | a drastic change: it predates the per-repo phases and still assumes a human schedules each confirmation cell |
| `05-harvest.md` | not live | a deep review, then rewriting as `05-harvest.md` in `plans/` - it is the first one worth doing, because harvest is what the winning cells are for |

| `08-agent-survey.md` | not live | a deep review; it may fold into harvest, its only real consumer |

Order of rework, when the time comes: 05 and 07 first as plans, then 04 and 06, then 08.
